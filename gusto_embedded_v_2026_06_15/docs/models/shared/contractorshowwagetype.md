# ContractorShowWageType

The contractor's wage type, either "Fixed" or "Hourly".

## Example Usage

```ruby
require "gusto_embedded_client_v_2026_06_15"

value = ContractorShowWageType::FIXED
```


## Values

| Name     | Value    |
| -------- | -------- |
| `FIXED`  | Fixed    |
| `HOURLY` | Hourly   |
