# BulkReportItemResultStatus

The terminal state for this individual report.

## Example Usage

```ruby
require "gusto_embedded_client"

value = BulkReportItemResultStatus::PENDING
```


## Values

| Name      | Value     |
| --------- | --------- |
| `PENDING` | pending   |
| `SUCCESS` | success   |
| `FAILED`  | failed    |
